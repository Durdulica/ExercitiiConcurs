# Invatare DP pentru ex8 (pas cu pas)

Ordine recomandata:

1. `pas1_linie_un_interval.h`
2. `pas2_linie_k_intervale.h`
3. `pas3_cerc_un_interval.h`
4. `pas4_cerc_k_intervale.h`

Ideea este sa inveti gradual:

1. mai intai intervalul maxim pe linie,
2. apoi exact `K` intervale pe linie,
3. apoi trecerea de la linie la cerc pentru `K=1`,
4. apoi varianta completa: cerc + exact `K` intervale.

Toate fisierele au:

1. enunt scurt in comentarii,
2. variabile cu nume clare in romana,
3. `assert` pe conditii importante,
4. functie `rezolvare()` gata de apel.
